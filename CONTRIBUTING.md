# Contributing to Destiny Global

First off, thank you for considering contributing to Destiny Global! It's people like you who make this project better for everyone.

---

## 🚀 How to Contribute

### 1. Reporting Bugs
- Check the [Issues](https://github.com/RaghavSobti37/destiny-global/issues) to see if the bug has already been reported.
- If not, create a new issue. Include as much detail as possible, such as steps to reproduce and screenshots.

### 2. Suggesting Enhancements
- Open a new issue with a clear title and description of the proposed enhancement.
- Explain why this enhancement would be useful to the project.

### 3. Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation in `DOCS/`.
4. Ensure the test suite passes (`npm run lint` and `npm run build`).
5. Make sure your code lints.
6. Issue that pull request!

---

## 🎨 Style Guide

### Code Style
- Use **functional components** and **React Hooks**.
- Follow the **Next.js App Router** patterns.
- Use **Tailwind CSS** for all styling. Avoid inline styles unless absolutely necessary for dynamic values.

### Commit Messages
We follow the **Conventional Commits** format:
- `feat: ...` for new features.
- `fix: ...` for bug fixes.
- `docs: ...` for documentation changes.
- `style: ...` for formatting, missing semi colons, etc.
- `refactor: ...` for code changes that neither fix a bug nor add a feature.

---

## 📐 Design Guidelines
Before making any UI changes, please review the [UI System Guide](DOCS/UI_SYSTEM.md). All new components should adhere to the established spacing and typography system.
